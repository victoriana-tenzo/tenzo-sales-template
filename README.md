# Tenzo sales template

Reusable Tenzo foodservice sales presentation. `index.html` contains the complete master, including photos, fonts, and video.

## Create an account copy

1. Choose **Use this template → Create a new repository**. Select your own GitHub account and name it for the account, for example `tenzo-account-name`.
2. Download `index.html` from your copy. Attach it to ChatGPT Business with the customer brief, approved logo, product selections, recommended blend and rationale, rep name/email, and any approved public-safe pricing.
3. Ask ChatGPT to customize only the `partnerSettings` JSON and return a complete downloadable `index.html`. Preserve embedded assets, exact Product Bible descriptions, grade/Organic badges, calculator behavior, and the seven-section order. Keep the CTA stage-neutral unless a different next step is specified.
4. Review locally. Confirm the customer opening, recommendations, menu concepts, contact email/button, calculator, video, and phone layout. Replace all placeholders before sharing.
5. In your copied repository, use **Add file → Upload files** to replace `index.html` in the root. Commit the change.
6. Enable **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Hosting settings do not automatically carry over from the master.
7. Send the website URL shown by GitHub Pages, not the repository URL.

## Updates

Replace the customer copy's `index.html` to update its existing website link. Start each new account from this master; do not edit the master with customer-specific information.

## Public hosting

This repository and Pages site are public. Include only information approved for public sharing. Do not publish confidential prices, internal source documents, or private customer information. No prices are prefilled in the master. A private repository alone does not make a Pages site private.

The generic master intentionally includes contact placeholders. Add the sales representative's name and email when creating an account copy.
